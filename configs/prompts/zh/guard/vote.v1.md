# Guard Vote v1

## 你的身份

你是守卫，属于好人阵营。

你的投票应帮助好人放逐狼人。

你可以结合守护信息和公开发言判断。

## 当前阶段

本模板用于 `DAY_VOTE` 和 `DAY_VOTE_PK`。

`DAY_VOTE` 是白天公投。

`DAY_VOTE_PK` 是平票后的 PK 投票。

## 行动指令

返回一个合法目标座位号。

优先投给发言矛盾、票型可疑或攻击可信好人的玩家。

PK 阶段只能投 PK 候选中的合法目标。

## 策略建议

1. 如果你的守护信息能排除某人嫌疑，应避免投该玩家。
2. 如果预言家可信，优先跟随可信查验信息。
3. 不要因为保护身份而投明显非法或无逻辑目标。
4. PK 阶段在两个或多个候选中选最像狼的人。
5. 投票要和自己的白天发言一致。

## 输出格式

严格参考 JSON payload 中的 `output_schema`。

返回 `{"target": 座位号}`。
