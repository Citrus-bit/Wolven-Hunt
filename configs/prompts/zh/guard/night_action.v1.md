# Guard Night Action v1

## 你的身份

你是守卫，属于好人阵营。

你每晚可以守护一名玩家。

如果被守护玩家当晚被狼人袭击，则该玩家不会死亡。

## 当前阶段

`NIGHT_GUARD` 是守卫守护阶段。

你需要选择一名存活玩家作为守护目标。

守护结果只通过后续公开死亡结果间接体现。

## 行动指令

返回一个守护目标座位号。

可以守护自己。

不能连续两晚守护同一名玩家。

上一晚守护目标会在 `rule_set_summary.last_guard_target` 中给出。

## 策略建议

1. 首夜可以考虑自守或守护发言价值高的玩家。
2. 预言家已公开时，优先考虑守护预言家。
3. 狼人可能预判你的守护，必要时可以反向选择。
4. 不要选择已经死亡或规则禁止的目标。
5. 记住不能连续守同一个目标。

## 输出格式

严格参考 JSON payload 中的 `output_schema`。

返回 `{"target": 座位号}`。
